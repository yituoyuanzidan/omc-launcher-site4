装哪一个先看你是哪种情况

我用 Windows 电脑玩 MC
下 Windows 版。解压到任意目录，双击 OMC.exe 就能开，第一次启动会自动检测 Java，没有就自己下。系统还在 Win7 / Win8 / 8.1 的，下老系统专用版。
我想在手机上用 OMC
不用装 App。电脑上开着 OMC，手机连同一个 WiFi，浏览器打开 http://电脑IP:8899，再点页面里的「添加到手机桌面」，桌面上就多一个 OMC 图标。步骤见下面这一节。
我要手机不接电脑、自己跑 Java 版
OMC 做不到这个，它的手机端只是遥控电脑的网页。得用第三方启动器（比如 FCL），它跟 OMC 是两套东西，本站不提供。
我用 Linux（Ubuntu / Debian / 国产 Linux）玩 MC
下 Linux 版。解压后进目录运行 ./OMC 就能开，界面和 Windows 版一模一样。依赖库已经全打进去了，不用额外装 Qt。
我用 Mac（M1 / M2 / M3 / M4 芯片）玩 MC
下 macOS 版（Apple 芯片）。解压得到 OMC.app，拖进「应用程序」就行。第一次打开请右键点图标选「打开」，因为没买苹果开发者签名；之后双击就正常了。
我用的是老款 Intel 芯片的 Mac
下 macOS 版（Intel），就是下载卡里那条 Intel 链接。这两个包不能混用：装错了会提示「应用程序无法打开」。不确定芯片就看屏幕左上角苹果标志 → 关于本机，那里写着「芯片」或「处理器」。
我用的是 Win7 / Win8 / 32 位系统
用不了 Windows 版。界面框架最低要求 Win10 64 位，这个限制改不掉。这类机器建议用 HMCL 或 PCL2。

手机端 OMC 手机控制台

OMC 自带的手机端，不是另一个 App。电脑开着启动器，手机浏览器连上去就是一个能点的界面，可以添加到手机桌面当图标用。

看怎么连上
装上之后不用再回来看这个页面。 Windows 版启动后会自动联网检查新版本，有新包就在后台自己下，下完问你要不要重启换上；设置里可以关掉这个开关。Linux 和 macOS 版这次是手动更新：新版本出来后重新下对应的包覆盖即可。

手机上怎么用 OMC不需要装任何 App

电脑上打开 OMC，记下它给出的局域网地址和端口，默认是 8899。
手机连同一个 WiFi，浏览器里输 http://电脑IP:8899，例如 http://192.168.1.5:8899。
点页面里的「添加到手机桌面」，手机桌面就多一个 OMC 图标，以后点开直接用，看着跟 App 一样。

为什么没有安卓 APK

  • OMC 没做安卓原生 App，手机端就是启动器自己开的那个本地网页，界面和功能跟着电脑上那份程序走。
  • 所以手机端显示的版本 = 你电脑上装的版本。电脑更新过了，手机刷新一下就是新的，不用另外装。
  • 手机和电脑要在同一个路由器下，跨网或用流量都连不上。
  • 如果要在手机上脱离电脑自己跑 Java 版 Minecraft，只能用第三方启动器（比如 FCL），那不是 OMC，本站不提供。

1.7.48 更新了什么2026-11-11

新增「娱乐」页，必须先登录才能进：左边栏「娱乐」，没登录只给一句提示和一个「去登录」按钮，登录之后才进得去。每个账号的积分各算各的，换个账号就是另一份，谁也不影响谁。页面左上角常驻一行红字「珍惜生命，远离赌博」——这里的积分是纯虚拟的，不能充值、不能换钱，玩的就是个乐。
六个玩法：五子棋、围棋、斗地主、一对一（21 点）、三连棋、猜拳：每个都能跟 AI 下一盘练手，也能邀请好友实时对局，还能走「匹配」在公共池里找陌生人打。跟 AI 那一路只练手，不结算积分；只有真人对局才算输赢。
积分怎么算：新号 500 分，输一盘扣自己当时积分的 10% 给对面：比如你有 500 分，输一盘扣 50 给对方、自己剩 450；下一次再输就按 450 算，扣 45。赢的一方直接收下这 10%。结算页会把谁赢谁输、扣了多少、从多少到多少逐条写清楚，下面还带最近 5 条积分流水，输赢都赖不掉。
顶栏「重置积分」，二次确认后才回到 500：点一下先弹确认框，默认停在「取消」，确认按钮写的是「确认重置」，怕手滑点错。确认之后分数回到 500，战绩一起清空；点取消就什么都不动，分数原样留着。
群聊加 @：能选人、@所有人，被 @ 的有专门提醒：输入框右边多了个「＠」按钮，点开能选群成员、@所有人，也能自己手打 @名字。被 @ 到的名字会高亮，自己被打上「@了你」。群没开免打扰的时候，托盘弹的是「有人@你 · 群名」，比普通新消息更显眼、还带提示音；群开了免打扰就照免打扰走，全局免打扰也拦得住。
群聊每条消息带头像：说话人旁边就是他自己的头像（头像库里那张）。本机没设过头像的，会带出对方客户端传过来的那张，换台电脑也认得出是谁，不会再是一排无名方块。
清缓存有进度条了：点清理先出扫描结果，再一格一格走百分比，底下实时显示「正在删：哪个文件、一共多少个」。清理期间三个按钮置灰，删完自动复原，不用盯着猜它到底在不在动。
「杰杰和麦琪」这类剧情短片拦得更狠：以前只认「杰杰」「麦琪」两个词，搬运号换个名字就漏进来。现在「小马厨房」「咕咕嘎嘎」，以及「咕嘎 / 比比拉布 + 我的世界」这种组合也一起拦，推荐、搜索、专区走的是同一道闸。正常生存实况、教学、实况解说一条都不误伤，实测拿真实搜索结果跑过一遍。

1.7.47 更新了什么2026-11-11

刷视频新增「专区」：可以只挑一个主播或一个服务器系列看：除了默认推荐，现在能锁定 USMP（Unstable SMP）、Technoblade（已逝）、Dream、ParrotX2、Wemmbu、FlameFrags、SpokeIsHere、Skeppy、GeorgeNotFound、Sapnap、Philza、CaptainSparklez、籽岷、老番茄、大橙子、芒果块、Acon、迪哥闯世界、小本解说、舞秋风、天骐、悠然小天、KingSight、卡哥，一共 24 个。已经走了的主播，作品照样在专区里留着。
每个专区可选看哪种：只看原视频 / 只看二创 / 全部都看：原视频只出他自己号发的东西，二创出剪辑、解说、熟肉、搬运这些，全部都看就是两种混着来，默认就是全部都看。不用每次自己去分辨哪条是本人发的。
涉政内容和违法违规视频自动拦掉：所有平台都拦，不用自己挑。标题、简介、标签、作者名四个地方都会查一遍，拦掉多少条会在状态行里写清楚。这一条不受「过滤」按钮里勾了什么影响，始终生效。
修「油管进度条在动但画面不正常」：以前回退的时候会挑到只有音轨的那一路，看着时间在走、画面全黑。现在只挑带画面的整段流；真遇到只有声音的片子，状态行会直接说这条只有声音、没有画面，并给出「在平台上打开」的按钮。
推荐不再是谁热度第一谁永远排第一：每条视频的分数都带一点随机浮动，前几名之间还会换位，同一批内容多刷几次顺序都不一样，翻到沉底老货的机会变多了。想找热门照样可以接着往下翻，只是不再被同一支片子卡在最前面。
修「播着一条，切到另一个平台还在响上一条的声音」：切平台会先把上一条彻底停掉，取新地址之前还会清空播放入口，出错也停；不会再出现画面换了、耳朵里还是上一条。
F11 全屏这回查到底也修到底了：先确认不是检测不到按键——六条快捷键全都建好了，每次按键都能收到，普通焦点、输入框焦点下都测过。真正的问题是两件：快捷键录入框录完键还攥着焦点，会把后面的按键吃掉；老代码里键盘兜底和快捷键会同时触发，一次按下去进全屏又立刻退出，看着就像没反应。现在录完键就还焦点，全屏键有统一兜底并加了防重复，按一下进、再按一下回来。
下载全面提速，Java 下载补上进度条：大文件自动开多路分块一起下，8MB 以上才开，某条路不稳就自己退回单路，不会卡在报错上；游戏本体那种本来就已经多线程并发的保持原样。Java 自动下载以前只有一行百分比文字，现在有真进度条，装完自己收起来。
AI 搭子小矿答得更准，也会自己找话题：末影龙怎么打、下界合金怎么弄、鞘翅在哪、床在下界为什么炸、区块加载慢这类问题，直接给能用的答案，不再滑到「我不敢乱说」；没话聊的时候它会自己接一句，不再复读客服话术。说「放首歌」也不会再把「首歌」当成歌名，现在会问你要听什么。私聊窗右键菜单也改成中文了：复制选中、全选、读出最后一条回复、清空对话。
设置里冲突的选项现在互斥：开了全局免打扰会自动取消「只关提示音」，反过来也一样；开了随机壁纸，固定壁纸下拉会变灰，但原来选的那张不会被清掉，关掉随机就回来。以前两个都勾着，实际按哪个生效谁也说不准。

刷过的不会再刷到，换一批也不会重复：以前一屏就 14 条，翻两下就开始撞车，同一支视频反复出现。现在这一轮已经刷到过的全部记下来，换一批、刷新、接着往下翻都绕开它们；记到 3000 条会自己回收，刷一整天也不会把内存吃满。过滤菜单里还多了一项「清空这次都刷过的记录」，想让旧的那批再出现，点一下就行。

修「点开卡在封面或第一帧」，F11 全屏真修好了：以前是先切画面再等缓冲，缓冲没到位就一直停在封面；现在等缓冲够了才切过去，三秒还没动静自动重试，重试两次仍不行才提示这条播不了。F11 之前像没反应，是窗口最小尺寸被内容撑得比屏幕还大——进全屏前先把限制松开，进去以后再补一次状态，现在按一下进、再按一下回来，原窗口大小和位置都记得。
起播更快，邮件角标即时跟上，AI 搭子能查资料：刷新列表时几路搜索同时发，只等最慢那一路；切上一条下一条先看有没有现成的播放地址，有就直接开播。离开视频页会自动停播，不在后台白吃几十兆内存。邮件读一封、全部已读、切列表，左栏红点立刻跟着变。小矿问「红石是什么」这类问题会先去联网查一遍再说，查不到就说不知道。

常见问题

打开 OMC.exe 被杀毒软件报毒、或者双击没反应怎么办
PyInstaller 打包的 exe 经常被误判成风险程序，这是启发式扫描的误报。1.7.9 起可以直接点设置页的「加入杀毒白名单」，或者右键以管理员身份运行包里的「加入白名单.bat」，省得手动找入口。双击没反应通常是压缩包没解压完就直接在压缩包里双击了，必须先完整解压。
第一次打开没有 Java，会不会开不了游戏
不会。启动器会先找系统里的 Java，找不到就自己下载一个 JRE 17 放到自己的数据目录（Windows 上是 %USERPROFILE%\.simple_mc_launcher\java\jdk17），下完自动填好路径。也可以在设置里手动指定已有的 Java。
手机端怎么连，为什么连不上
手机和电脑必须连同一个路由器（同一个 WiFi）。电脑上开着 OMC，看页面显示的地址，一般是 http://电脑局域网IP:8899，手机浏览器直接输进去。连不上多半是 Windows 防火墙拦了这个端口，放行一次即可；用手机流量、或者电脑连的是热点另一侧，都不通。
FCL 装完开游戏很卡、或者崩
FCL 是在手机上跑桌面版 Java，很吃内存和芯片。进 FCL 设置里把分配给游戏的内存调到 2G 左右（机身内存 8G 以上再往上加），渲染器优先选适合机型的那一档，光影基本别开。低端机跑 1.16 以上版本通常比较勉强。
自动更新会不会把我自己改过的文件覆盖掉
会。更新是整目录覆盖，只有你自己放在安装目录外面的东西不受影响。配置、存档、模组库都在 .simple_mc_launcher 数据目录里，不在安装目录，所以不会被覆盖。如果你手动改过安装目录里的程序文件，建议关掉设置里的自动更新。
为什么 Mac 上不能自动更新
macOS 上 .app 是个目录包，程序在运行时替换自己被系统拦下，所以只能手动换：检测到新版会提示你去下载，然后把新的 OMC.app 拖进「应用程序」覆盖（拖之前先退出旧版）。Windows 和 Linux 的包可以直接自己换。
