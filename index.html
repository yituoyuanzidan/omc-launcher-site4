手机端 OMC 手机控制台

OMC 自带的手机端，不是另一个 App。电脑开着启动器，手机浏览器连上去就是一个能点的界面，可以添加到手机桌面当图标用。

装上之后不用再回来看这个页面。 Windows 版启动后会自动联网检查新版本，有新包就在后台自己下，下完问你要不要重启换上；设置里可以关掉这个开关。

手机上怎么用 OMC不需要装任何 App

电脑上打开 OMC，记下它给出的局域网地址和端口，默认是 8899。
手机连同一个 WiFi，浏览器里输 http://电脑IP:8899，例如 http://192.168.1.5:8899。
点页面里的「添加到手机桌面」，手机桌面就多一个 OMC 图标，以后点开直接用，看着跟 App 一样。

为什么没有安卓 APK

  • OMC 没做安卓原生 App，手机端就是启动器自己开的那个本地网页，界面和功能跟着电脑上那份程序走。
  • 所以手机端显示的版本 = 你电脑上装的版本。电脑更新过了，手机刷新一下就是新的，不用另外装。
  • 手机和电脑要在同一个路由器下，跨网或用流量都连不上。
  • 如果要在手机上脱离电脑自己跑 Java 版 Minecraft，只能用第三方启动器（比如 FCL），那不是 OMC，本站不提供。

邮箱验证码注册 / 登录：注册要填用户名、邮箱、6 位验证码，密码写一遍再确认一遍；用户名在本机不能重复（不区分大小写），邮箱也只能绑一个账号。验证码用 QQ 邮箱发出去——在账号页右上角「发信邮箱」里填发信邮箱和授权码（不是登录密码），一次配好长期用。

常见问题

打开 OMC.exe 被杀毒软件报毒、或者双击没反应怎么办
PyInstaller 打包的 exe 经常被误判成风险程序，这是启发式扫描的误报。1.7.9 起可以直接点设置页的「加入杀毒白名单」，或者右键以管理员身份运行包里的「加入白名单.bat」，省得手动找入口。双击没反应通常是压缩包没解压完就直接在压缩包里双击了，必须先完整解压。
第一次打开没有 Java，会不会开不了游戏
不会。启动器会先找系统里的 Java，找不到就自己下载一个 JRE 17 放到自己的数据目录（Windows 上是 %USERPROFILE%\.simple_mc_launcher\java\jdk17），下完自动填好路径。也可以在设置里手动指定已有的 Java。
手机端怎么连，为什么连不上
手机和电脑必须连同一个路由器（同一个 WiFi）。电脑上开着 OMC，看页面显示的地址，一般是 http://电脑局域网IP:8899，手机浏览器直接输进去。连不上多半是 Windows 防火墙拦了这个端口，放行一次即可；用手机流量、或者电脑连的是热点另一侧，都不通。
FCL 装完开游戏很卡、或者崩
FCL 是在手机上跑桌面版 Java，很吃内存和芯片。进 FCL 设置里把分配给游戏的内存调到 2G 左右（机身内存 8G 以上再往上加），渲染器优先选适合机型的那一档，光影基本别开。低端机跑 1.16 以上版本通常比较勉强。
自动更新会不会把我自己改过的文件覆盖掉
会。更新是整目录覆盖，只有你自己放在安装目录外面的东西不受影响。配置、存档、模组库都在 .simple_mc_launcher 数据目录里，不在安装目录，所以不会被覆盖。如果你手动改过安装目录里的程序文件，建议关掉设置里的自动更新。
为什么 Mac 上不能自动更新
macOS 的 .app 是签名过的包，程序自己替换自己会被系统拒绝。所以在 Mac 上检测到新版只会提示你去下载，然后手动把新的 OMC.app 拖进应用程序目录覆盖。Windows 和 Linux 是可以自己换的。
